About & Compliance

Application Overview

YTS Budget Analysis is a financial data extraction and visualization tool for Yewtree Square Owner's Management Company (OMC).

Technical Approach
  • Rule-Based Processing: Uses pattern matching and text extraction (no AI/ML)
  • Deterministic Results: Same input always produces same output
  • Transparent Operations: All processing is logged and auditable
  • Local Storage: Data stored locally only (no cloud transmission)
Data Processing
  • Input: PDF documents (budgets, accounts, AGM minutes)
  • Processing: Text extraction → Pattern matching → Categorization → Storage
  • Output: Dashboards, charts, reports, gap analysis
  • Data Type: Financial service charges only (no personal data)
